Diccionario

Definiciones

Actuador

Elemento que recibe una señal del sistema y realiza una acción física, como encender una luz, mover un motor o activar un zumbador.

Arduino

Placa electrónica programable que permite controlar sensores y actuadores para crear proyectos tecnológicos y sistemas automáticos.

Automatización

Uso de la tecnología para que un sistema funcione de forma automática sin intervención humana directa.

Circuito eléctrico

Conjunto de elementos conectados que permiten el paso de la corriente eléctrica para que un dispositivo funcione.
