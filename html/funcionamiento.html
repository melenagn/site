LA CASA INTELIGENTE

Funcionamiento

Condiciones y requisitos

La vivienda inteligente detecta las condiciones de luz ambiental y la presencia de lluvia mediante dos sensores:

Sensor de luz (LDR): Cuando el fotosensor detecta oscuridad (por ejemplo, al taparlo simulando la noche), las luces de la casa se encienden automáticamente.
Sensor de lluvia: Situado en una placa colocada sobre el tejado, permite detectar gotas de agua. Si se vierten gotas con un cuentagotas para simular la lluvia, el sistema activa un servomotor que recoge el tendedero, desplazándolo hacia la zona protegida bajo el alero del tejado.
De esta manera, el proyecto reproduce de forma sencilla y visual cómo funcionan algunos sistemas automatizados presentes en las viviendas inteligentes actuales.
