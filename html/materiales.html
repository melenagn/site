LA CASA INTELIGENTE

Materiales

Componentes electrónicos

  1. Controladora de Placa Arduino UNO
  2. Cable USB para conexión y programación.
  3. Protoboard para realizar las conexiones sin soldadura.
  4. Juego de cables Dupont (macho–macho, macho–hembra y hembra–hembra).
  5. Sensor de luz (LDR) y resistencia de 1 kΩ.
  6. Sensor de lluvia con su módulo controlador.
  7. Servomotor para el movimiento del tendedero.
  8. Diodos LED para iluminación exterior.
  9. Resistencias varias (220 Ω, 330 Ω…).
  10. Fuente de alimentación si se desea uso sin conexión al ordenador.

Materiales para la maqueta

  • Cartón pluma, cartón rígido o madera fina para las paredes y estructura.
  • Pistola de silicona y barras adhesivas.
  • Palillos, pajitas o perfiles de madera para refuerzos estructurales.
  • Ventanas y puertas (pueden fabricarse con acetato y cartón).
  • Tejado realizado con cartón o materiales reciclados.
  • Superficie base (cartón pluma o tabla MDF).
  • Guías o varillas para el desplazamiento del tendedero.
  • Hilo o alambre fino para unir el tendedero al servomotor.
  • Soportes para fijar sensores, servomotor y cableado.

Herramientas

  • Tijeras y cúter (bajo supervisión).
  • Regla y escuadra.
  • Destornillador pequeño.
  • Cinta adhesiva y cinta aislante.
